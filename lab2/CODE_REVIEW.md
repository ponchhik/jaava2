# Проверка кода — лабораторная работа № 2, вариант 10

Проверено 26.10.2026 на Java 21. Основная реализация — собственное дерево интервалов (BST + `maxEnd`) в `booking.ds.IntervalTree`.

## Внесённые изменения

1. `gui/BgTask.java` и `gui/MainPanel.java`: вместо немедленной отмены SwingWorker через `cancel(false)` применяется кооперативный флаг. Обработчик завершения запускается после окончания фонового `doInBackground`; прерывание обрабатывается с передачей ошибки в `onError`.
2. `io/CsvSaver.java`: запись сперва в временный файл; при успешном завершении — замена целевого CSV (`ATOMIC_MOVE`, при отсутствии поддержки обычный `REPLACE_EXISTING`); на отмену цикл реагирует без изменения целевого файла.
3. `service/BookingGenerator.java`: ключевые вероятности и интервалы длительности вынесены в именованные константы.
4. `experiment/FocusedTests.java`: шесть независимых сценариев — вставка/поиск, удаление, границы пересечения, конфликт комнаты, ошибка дубликата CSV, отменённое сохранение.
5. `build.gradle`: отдельная задача `focusedTest`.

## Проверки

`javac -encoding UTF-8`: успешно, Java 21.

`FocusedTests`: **6 из 6 успешно**.

`SelfTest`: успешно, 20 000 случайных шагов, 4 015 проверок запросов, финальная высота дерева 22.

`RaceDemo`: в тестовом запуске при 200 000 ожидаемых узлов незащищённый код давал гонку; обёртка `SynchronizedIntervalStore` сохранила все 200 000 узлов, инварианты не нарушены.

`Benchmark`: выполнен, результаты зависят от среды и нагрузки.

Графический интерфейс Swing запущен; созданы два реальных скриншота, включённые в отчёт.

**Проверка Gradle Wrapper в этой среде не завершена:** загрузка дистрибутива Gradle 9.6 из `services.gradle.org` заблокирована отсутствием сетевого доступа. При наличии JDK 21 и интернета используйте `./gradlew focusedTest selfTest`.

## Состояние по пяти пунктам антипаттернов

- **Логика в GUI:** алгоритмы структуры и CSV выделены в отдельные слои. Однако MainPanel/QueryPanel ещё выполняют некоторые операции через `service.store()`; для более строгой слоистой архитектуры стоит закрыть хранилище фасадом BookingService.
- **Пустые catch:** не обнаружены. Присутствуют перехваты с обработкой/учётом ошибок.
- **Магические значения:** ключевые параметры генерации вынесены в константы, `Trace.Kind` и `LoadErrorCode` — enum. Локальные числа оформления интерфейса остаются параметрами представления.
- **Тест «всё сразу»:** стресс-проверка SelfTest сохранена отдельно, есть шесть небольших независимых тестов.
- **Операции GUI дольше 100 мс:** длительные задачи выполнены через SwingWorker. Измерение синхронного `refresh` при 100 000 записей дало около 19–33 мс в проверенной среде; на другой машине или при другом распределении данных возможны более длинные блокировки. При необходимости дальнейшая оптимизация — фоновая подготовка снимков и запросов.
